\section{Conclusion}

Recommender systems play an important role in shaping how users interact with digital platforms.
While modern recommendation algorithms have achieved significant success in predicting user interactions, 
many systems continue to focus primarily on short-term engagement metrics.
This optimization objective overlooks important aspects of the user experience, including cognitive fatigue, content repetition, and long-term satisfaction.

This work proposes a Dual-System Human-Centric Recommender System designed to address these challenges.
The proposed framework introduces a dual recommendation architecture consisting of a fast engagement-focused model and a long-term optimization component.
By incorporating a fatigue estimation module and an adaptive gating mechanism, 
the system can dynamically adjust recommendation strategies based on the user's interaction context.

In addition to proposing this architecture, the report outlines a comprehensive evaluation framework that includes both
traditional ranking metrics and additional indicators for the other modules of the framework.

Although the proposed system remains conceptual at this stage, it provides a structured approach for integrating 
behavioral prediction, cognitive modeling, and long-term optimization within a unified recommendation framework.
Through this work, we aim to contribute towards the goal of designing recommender systems that 
are not only accurate but also adaptive, sustainable, and aligned with long-term user wellbeing.
