# System 1 vs System 2 Recommendation


This is borrowed from psychology (Daniel Kahneman).

- System 1 = Fast, impulsive, reactive
    
- System 2 = Slow, reflective, long-term thinking
    

In recommender terms:

**System 1 recommender:**

- Maximizes immediate clicks
    
- Shows what grabs attention
    
- Optimizes short-term engagement
    

**System 2 recommender:**

- Optimizes long-term satisfaction
    
- Balances novelty and familiarity
    
- Avoids burnout

# Addiction Aware


### System-1 (Impulsive / Moreishness)

This is:
- Instant gratification
- Dopamine-driven
- Habitual scrolling
- Clickbait

Properties:
- Strong short-term effect
- Decays quickly
- Creates a temporary spike in return probability

Example:
You binge 10 reels tonight.  
Tomorrow morning you feel the urge to open the app again.  
But that urge fades quickly.


## System-2 (Utility / Long-term value)

This is:
- Meaningful content
- Learning something useful
- Getting value aligned with goals

Properties:
- Smaller short-term spike
- Longer-lasting effect
- Drives sustained retention

Example:
You watch a high-quality ML lecture series.  
You return next week to continue learning.

# A user might keep returning even if the platform only shows moreish content.

Because if System-1 spikes are large enough and frequent enough, they can sustain repeated returns — even if utility is low.

This models:
- Doomscrolling
- Habit loops
- Short-term addictive usage

They are **not** modeling cases like:
- Clinical addiction
- Compulsive behavior independent of content quality
- Structural habit loops that persist even without gratification

Their model still assumes:
> Return probability depends on past experience.
