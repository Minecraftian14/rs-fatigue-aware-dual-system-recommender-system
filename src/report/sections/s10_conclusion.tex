Recommender systems play an increasingly important role in shaping how users interact with digital platforms.
While modern recommendation algorithms have achieved significant success in predicting user interactions, many systems continue to focus primarily on short-term engagement metrics.
This narrow optimization objective may overlook important aspects of the user experience, including cognitive fatigue, content repetition, and long-term satisfaction.

This work proposes a Dual-System Human-Centric Recommender System designed to address these challenges.
The proposed framework introduces a dual recommendation architecture consisting of a fast engagement-focused model and a long-term optimization component.
By incorporating a fatigue estimation module and an adaptive gating mechanism, the system attempts to dynamically adjust recommendation strategies based on the user's interaction context.

In addition to proposing this architecture, the report outlines a comprehensive evaluation framework that includes both traditional ranking metrics and additional indicators related to diversity, novelty, fatigue, and long-term engagement.
These evaluation criteria aim to provide a more holistic view of recommender system performance.

Although the proposed system remains conceptual at this stage, it provides a structured approach for integrating behavioral prediction, cognitive modeling, and long-term optimization within a unified recommendation framework.
Future work will focus on implementing the system, conducting empirical evaluations on social media interaction datasets, and exploring how fatigue-aware recommendation strategies influence user experience over extended periods.

Through this work, we aim to contribute toward the broader goal of designing recommender systems that are not only accurate but also adaptive, sustainable, and aligned with long-term user wellbeing.
